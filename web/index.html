1

Transparansi model

Apa yang ada di balik aplikasi?

NusantaraEdu-NER menggunakan model Named Entity Recognition (NER) berbasis spaCy yang dilatih pada anotasi entitas budaya Indonesia. Aplikasi tidak menebak fakta baru; ia menandai bagian teks berdasarkan pola yang dipelajari model.

Metrik test set membantu menilai model secara agregat, tetapi tidak menjamin setiap prediksi selalu benar.
